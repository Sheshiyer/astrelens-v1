### Step 1: Create Notebook

2. Click "New Notebook"
3. Name: **"AstroLens Brand Intelligence"**

### Step 2: Upload Sources
1. Click "Add Source"
2. Select all 8 markdown files (01-08)
3. Wait for processing (1-2 minutes)
